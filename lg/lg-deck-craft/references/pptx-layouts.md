# PPTX 版式规范

## 画布

- 16:9，默认 13.333 × 7.5 英寸。
- 上传模板时读取模板尺寸；读不到用默认值。

## 版式类型

| visual | 用途 | 结构 |
|---|---|---|
| `cover` | 封面 | 深色底 + 主标题 + 副标题 |
| `section` | 章节页 | 深色底 + 章节标题 |
| `content` | 常规内容 | 标题 + ≤5 条要点 |
| `chart` | 数据页 | 标题 + 原生柱状图/折线图 |
| `timeline` | 时间轴 | 标题 + 编号条目 |
| `compare` | 对比页 | 标题 + 左右两栏 |
| `quote` | 金句页 | 居中大字 |
| `end` | 结束页 | 深色底 + Q&A |

## 规则

- 每页一个观点；标题就是结论句。
- 正文不超过 80 个中文字符；要点不超过 5 条。
- 图表必须可编辑（pptxgenjs 原生图表），不要贴图片。
- 每页必须有讲述稿，写入 notes。

## 模板继承

- 优先读取 `ppt/theme/theme1.xml` 的配色与字体；
- 读取 `ppt/presentation.xml` 的画布尺寸；
- 读不到时降级为内置主题，并在评分卡提示 `degraded: true`。
